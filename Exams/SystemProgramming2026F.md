# 二进制加法

## 题目描述

给你两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。

## 输入格式

第一行输入一个二进制字符串 `a`（仅由字符 `'0'` 或 `'1'` 组成）。

第二行输入一个二进制字符串 `b`（仅由字符 `'0'` 或 `'1'` 组成）。

## 输出格式

输出一个二进制字符串，表示 `a + b` 的结果。结果不含前导零（除非结果本身就是 `"0"`）。

## 数据范围

- `1 <= a.length, b.length <= 10000`
- `a` 和 `b` 仅由字符 `'0'` 或 `'1'` 组成
- 字符串如果不是 `"0"`，就不含前导零

## 示例

### 示例 1：

```javascript
输入:
11
1

输出:
100
```

### 示例 2：

```javascript
输入:
1010
1011

输出:
10101
```

## 提示

二进制加法与十进制加法类似，从最低位（最右边）开始逐位计算：

1. 当前位结果 = `a的该位` + `b的该位` + `进位`
2. 若结果 >= 2，则结果减 2 并向高位进 1
3. 所有位处理完后，若仍有进位则补上
4. 如果计算结果低位在前面，在输出时反转结果

**示例：`11 + 1 = 100`**

```javascript
      1 1
    +   1
    -----
```

从右到左：

- 第1位：1 + 1 = 2 → 0，进位
- 第2位：1 + 0 + 1 = 2 → 0，进位
- 进位：1

结果：100

# 题目：内存分配

## 题目名称

动态成绩表

## 题目描述

某班有 `n` 名学生，每名学生有 `m` 门课程成绩。请编写一个 C 或 C++ 程序，使用动态内存分配保存所有成绩，并完成以下统计：

1. 输出每名学生的总分；
2. 输出所有学生所有课程中的最高分；
3. 输出所有学生所有课程中的平均分，保留 2 位小数。

要求：

- C 语言程序应使用 `malloc` `calloc` `free` 等方式申请和释放内存；
- 不要使用固定大小的二维数组，例如 `int a[100][100]`。

## 输入格式

第一行输入两个整数 `n` 和 `m`，分别表示学生人数和课程门数。

接下来 `n` 行，每行输入 `m` 个整数，表示一名学生的各门课程成绩。

## 输出格式

第一行输出 `n` 个整数，表示每名学生的总分，整数之间用一个空格分隔。

第二行输出一个整数，表示最高分。

第三行输出一个实数，表示平均分，保留 2 位小数。

## 数据范围

- `1 <= n <= 100`
- `1 <= m <= 20`
- 每门成绩为 `0` 到 `100` 之间的整数

# 平方求和程序性能优化

## 题目描述

给定无符号整数 `rounds` 和 `target`，计算 `[0, rounds)` 范围内满足“该数十进制的个位数字和十位数字和为 `target`”的所有整数平方和。

 

要求：

- 使用 `unsigned int` 表示核心变量，这样它们会在 232232 自动溢出到 `0`。
- 尽量优化程序的性能，但不要用直接用数学公式从 rounds 和 target 计算出结果。（应该也计算不出结果）

## 输入格式

两个整数 `rounds` 和 `target`，分别表示枚举上界和目标个位十位数字和。

## 输出格式

输出计算得出的平方和 `sum`。

## 数据范围

- `rounds >= 1`，可以用 `unsigned` 表示
- `0 <= target <= 18`

 

## 提示

未优化版代码示例：

```c
#include <stdio.h>
int main()
{
    unsigned rounds;
    unsigned target;
    scanf("%u %u", &rounds, &target);
    // uint64_t time = __rdtsc(); 计时
    unsigned sum = 0;
    unsigned i;
    for (i = 0; i < rounds; i++)
    {
        if ((i % 100) / 10 + (i % 100) % 10 == target)
        {
            sum += i * i;
        }
    }
    // uint64_t time2 = __rdtsc(); 计时
    printf("%u", sum);
    return 0;
}
```

你可以从以下方式尝试优化：

- 消除重复的计算，尤其是 `%` 模运算
	- 思路： 将循环内重复计算的 `i % 100` 等模运算结果存入临时变量，避免重复执行耗时的除法指令。
- 在循环外提前计算 100 以内的个十位和
	- 思路： 预先生成 0-99 所有数的个十位和对照表，主循环中直接查表判断，避免重复拆分数字。
- 减少循环次数
	- 思路： 利用 “个十位和” 条件的周期性规律，批量处理完整周期，仅单独处理末尾不足一个周期的部分。
- 在满足条件时再累加平方项，例如 `sum += i * i`

补充说明：循环展开在此题中效果不佳，因为循环内存在条件判断，打乱了指令流水线的并行执行。
